# DataForSEO fixtures

Synthetic answers in the shape DataForSEO's Labs endpoints document, with the
dummy figures the **sandbox** returns (round numbers, a fixed task id). They
were written by hand for the parsers' tests; none is a recorded live answer,
and no figure in them is a real estimate for any keyword. Never add a live
response here: the repository is public, and a live answer carries the
account's task ids and spend.
